# SEOHEE LEE — Portfolio

Official portfolio website for artist Seohee Lee.

## Content editing

The site content is stored in `data/` and can be edited through Pages CMS using `.pages.yml`.

- `data/site.json`: introduction and contact details
- `data/works.json`: artworks
- `data/exhibitions.json`: exhibitions
- `assets/images/`: uploaded artwork and exhibition images

The public site is deployed with GitHub Pages from the `main` branch.
